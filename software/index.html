Software

Open-source code accompanying my research. More repositories are on GitHub and the BorgwardtLab organization.

Graphs and structured data

  • AutoGraph: graph generation by flattening graphs into sequences and training transformers on them.
  • PolyGraph: a classifier-based metric and benchmark for evaluating graph generative models.
  • NeuralWalker: learning long-range dependencies on graphs via random walks.
  • SAT: Structure-Aware Transformer. Graph transformers whose self-attention incorporates structural information by extracting a subgraph representation rooted at each node, using any existing GNN as the structure extractor.
  • GraphiT: a transformer for graph-structured data that encodes graph structure through relative positional encodings based on graph kernels and through local substructures around each node.
  • GCKN: graph convolutional kernel networks for modeling graph-structured data.
  • OTK: optimal transport kernel for feature aggregation (adaptive pooling with attention) on any data represented as sets of features. Usable as a neural network module or as a standalone kernel method.

Proteins and biological sequences

  • TEDBench: benchmark for protein fold classification at scale.
  • PST: protein structure transformer that endows protein language models with structural knowledge.
  • ProteinShake: one-liner imports of large-scale, preprocessed protein structure tasks and datasets for various model types and frameworks.
  • ProLlama: train a Llama model on protein sequences with PyTorch Lightning and Hydra (see the blog post).
  • RKN: recurrent kernel networks for biological sequences (DNA, proteins) with potentially gapped motifs.
  • CKN-seq: convolutional kernel networks for biological sequences.

Other
